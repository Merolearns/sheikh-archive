# DECISIONS.md — judgment calls made during the v2 rebuild

(Entries appended as made. Each: what was decided, why.)

## Takeover from the interim agent (2026-10-29)

1. **Kept as-is:** `build/Preview/archive_server.py` (baseline + `/__status` + startup videos-folder log), both launchers (verified byte-identical: Windows vs `archive-baseline/working`, macOS vs `archive-baseline/redesign-v1/Start Archive - macOS.command`), the 7 WOFF2 fonts (checked with fontTools: GSUB/GPOS/GDEF kept, U+06DD, U+0670, U+08F0, U+FDFA present; Amiri Quran covers every glyph of the opening verse), and the DATA-splice + deep-equal approach from `build-early.py`.
2. **Shelved (moved to `src/interim-unused/`, not in the build):** the four parallel track modules and the early build. Reasons: never integrated (no core/shell existed), and they conflicted with the brief: emoji icons on Mission (clip-art feel), an invented descriptor of the Sheikh ("Arabic Islamic scholar") and a misspelled English name ("Mostafa"), splash image path `assets/img/...` that would 404 because the page is served at `/` while assets live in `Preview/assets/`, and a recitation button on the opening (the brief allows only the verse, citation, name and ONE Enter button there). Brief wins. The app was rewritten as one coherent CSS/HTML/JS set; useful copy ideas were carried over.
3. **sunset.svg replaced:** the interim drawing used mountains and rectangle minarets. Rebuilt as an indigo-to-amber dusk with layered dome-and-minaret silhouettes, palms, and a gold double-rule border with 8-point star corners.
4. **macOS launcher filename:** the brief names it `Start_Archive_-_macOS.command`; the content is byte-identical to the redesign-v1 launcher. Filename follows the brief.

## Build decisions (2026-10-29)

5. **Structure:** `src/app.css`, `src/body.html`, `src/app.js` + `build.py` (assembles, deep-equal checks DATA, `node --check`, refuses em dashes and external URLs in src). Single page, hash routes `#/home #/library #/playlist/<id> #/lesson/<id> #/start #/saved #/about #/mission #/sheikh`.
6. **Fixed chrome:** `<html dir="rtl">` never changes. Every text block carries its own `lang`/`dir`. Lesson titles, series titles and eyebrows are always `lang="ar" dir="rtl"` because the catalog's `titleEn` is empty for all 3,977 lessons (checked). Only the in-content prev/next chevrons and breadcrumb arrows mirror per block. Rail scroll arrows are chrome and stay fixed.
7. **Storage keys shared with v1:** favourites `archive-favorites-v4` and progress `archive-progress-v4` (same `{id:true}` / `{id:seconds}` shapes), so the owner's existing saved lessons and progress carry over. New v2 keys are prefixed `archive-v2-`.
8. **Opening:** shown once per browser session (sessionStorage), skippable with Escape (silent). `?splash=1` forces it, `?splash=0` skips it. Verse uses U+06DD + ١١٤ (the end of 20:114), rendered by Amiri Quran. The verse itself is never animated; only the citation, name and button fade in.
9. **Recitation slot:** a single audio manager in the footer (play/pause, replay, mute, volume; volume and mute persisted). It stops when a lesson plays and pauses the lesson when it plays. Availability comes from a new `recitation` boolean in `/__status` (server checks `Preview/assets/recitation.mp3`). This avoids a 404 console error from probing a missing file. `/__status` keeps the brief's two fields unchanged.
10. **Listen control placement:** the brief allows only one button on the opening, so the Listen control lives in the footer of every page. With no file it is disabled and shows "Recitation licence pending, no recording bundled."
11. **Scholars rail:** two cards. Sheikh Dr. Moustafa Kamel (calligraphic monogram, counts from the catalog) and Dr. Imad Bayoun, because the playlist "Aqeeda by Dr Imad Bayoun" names him. Scholar lines say "Dr. Imad Bayoun" only for that series; every other lesson is credited to the Sheikh, on the basis that this is his archive.
12. **Featured series** (hand-picked by title, IDs copied from DATA): Tafsir, Sahih al-Bukhari, Seerah, Asma al-Husna, Fiqh al-Ibadat, Tazkiyat al-Nufus, Tajweed, Shama'il.
13. **Where to Start mapping** (shown as "[to be confirmed]"): 1 Beliefs: Asma al-Husna, al-Fiqh al-Amm (Tawhid). 2 Worship: Fiqh al-Ibadat, Zakat Q&A. 3 Seerah: al-Sirah al-Nabawiyya, Shama'il. 4 Qur'an: Tajweed, Tafsir. 5 Character: Silsilat al-Akhlaq, Tazkiyat al-Nufus. 6 Deeper: Usul al-Fiqh, al-Bayquniyya, Sahih al-Bukhari. First session: the earliest upload of Asma al-Husna ("١- سلسلة أسماء الله الحسنى", 13:19), shown with its real length.
14. **Playlist order:** the catalog's item order is the channel's own and is mostly newest-first, so it is not teaching order. The catalog is untouched. The default sort is labelled "Playlist order", and "Start" buttons go to the earliest upload, labelled "Start with the earliest lesson" rather than "lesson 1".
15. **Library sidebar (8 items):** All series, All lessons, Lectures, Live streams, Shorts (from `categories`), Lessons outside a series (246), In progress, Saved. 36 cards per page with "Show more".
16. **Search:** Arabic-normalised (diacritics, alef/ya/ta-marbuta forms, Arabic-Indic digits). Inside a playlist it is scoped, with a "Search the whole library" escape.
17. **Languages & Text:** the button appears only on lessons that list ar/en subtitles. Captions are fetched on demand into a 4-item memory cache. Transcripts are fetched on demand and persisted in a small localStorage cache (6 texts, each under 250 KB).
18. **Player errors:** on `error`, HEAD-probe the media URL. 404 shows "not found" with the decoded expected path (plus a line if `/__status` says the videos folder is missing). Anything else shows the VLC format message and an "Open the file directly" link.
19. **Continue Watching with no progress:** the button stays, scrolls to the rail, and the rail's empty state points to Where to Start.
20. **Theme swatches** are live previews: each swatch carries its own `data-theme`, so it renders in that theme's tokens.
21. **Recitation footer and copy:** no em dash anywhere in src (build-enforced). Honorific ﷺ written as the single character in text that mentions the Prophet.
22. **Testing artefacts** live outside `build/`: `testroot/` (stand-in archive with generated media), `shots/`, `tools/`. The interim agent's leftover server on port 8765 (cwd /tmp/archtest) was stopped so tests could use the real port.
